# JavaScript - Full Stack Development

## 🎯 Objetivos
- Dominação completa de JavaScript (ES6+)
- Frontend: React
- Backend: Node.js + Express
- APIs REST

## 📚 Conteúdo do Curso
1. Fundamentos (variáveis, funções, escopo)
2. Arrays, Objetos e Destructuring
3. Promises, Async/Await
4. Modules (ES6 Modules, CommonJS)
5. DOM Manipulation
6. Fetch API & AJAX
7. Node.js + Express
8. React (componentes, hooks, state)
9. Testing (Jest)
