# ✅ Performance Optimization Checklist

Use para otimizar performance de aplicação.

---

## 📊 Análise

- [ ] Identificar bottlenecks (profiling)
- [ ] Coletar métricas baseline
- [ ] Definir meta de performance

---

## 🗄️ Banco de Dados

- [ ] N+1 queries eliminadas
- [ ] Índices criados onde necessário
- [ ] Queries otimizadas (EXPLAIN)
- [ ] Caching implementado
- [ ] Connection pooling configurado

---

## 💻 Backend

- [ ] Algoritmos otimizados
- [ ] Lazy loading implementado
- [ ] Async operations onde applicable
- [ ] Memory leaks corrigidos
- [ ] Logging não impacta performance

---

## 🎨 Frontend

- [ ] Bundle size reduzido
- [ ] Images otimizadas
- [ ] Code splitting implementado
- [ ] CSS minificado
- [ ] JavaScript minificado
- [ ] Sem render waterfalls

---

## 🚀 Deployment

- [ ] CDN configurado
- [ ] Compression habilitado (gzip)
- [ ] Caching headers corretos
- [ ] Load balancing (if needed)

---

## ✅ Validação

- [ ] Performance melhorou vs baseline
- [ ] Meta atingida
- [ ] Nenhuma regressão
