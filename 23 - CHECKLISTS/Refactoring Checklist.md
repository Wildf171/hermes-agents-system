# ✅ Refactoring Checklist

Use antes de fazer refatoração de código.

---

## 🔍 Preparação

- [ ] Testes existentes passam
- [ ] Cobertura de testes >80%
- [ ] Branch separado criado
- [ ] Escopo definido

---

## 🔄 Durante Refatoração

- [ ] Testes passam a cada passo
- [ ] Sem mudar comportamento
- [ ] Pequenos commits com propósito claro
- [ ] Code review em paralelo

---

## ✅ Verificação

- [ ] Todos os testes passam
- [ ] Performance não piorou
- [ ] Code smells removidos
- [ ] Documentação atualizada

---

## 📊 Review

- [ ] Antes e depois são legíveis
- [ ] Melhorias são claras
- [ ] Nenhuma regressão
