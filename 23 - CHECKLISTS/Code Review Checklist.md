# ✅ Code Review Checklist

Use ao revisar Pull Requests.

---

## 🎯 Objetivo

- [ ] Objetivo da PR está claro?
- [ ] Escopo está apropriado?
- [ ] Não está resolvendo múltiplos problemas?

---

## 💻 Qualidade de Código

- [ ] Código segue convenções do projeto
- [ ] Nomes são claros e descritivos
- [ ] Sem código duplicado
- [ ] Sem commented code
- [ ] Sem console.log/print statements

---

## 🏗️ Arquitetura

- [ ] Segue padrões do projeto
- [ ] Separação de concerns
- [ ] Sem acoplamento desnecessário
- [ ] SOLID principles

---

## 🧪 Testes

- [ ] Testes cobrem casos principais
- [ ] Edge cases testados
- [ ] Testes são legíveis
- [ ] Coverage aceitável (>80%)

---

## 📚 Documentação

- [ ] Código está bem comentado (se necessário)
- [ ] README atualizado
- [ ] API documentation (if applicable)

---

## ⚠️ Segurança

- [ ] Sem secrets/passwords no código
- [ ] Input validation está presente
- [ ] SQL injection protegido (if applicable)
- [ ] CORS configurado corretamente

---

## ⚡ Performance

- [ ] Sem N+1 queries
- [ ] Loops desnecessários?
- [ ] Memory leaks?
- [ ] Algoritmo eficiente?

---

## ✅ Aprovação

- [ ] Aprovar a PR
- [ ] Ou solicitar changes
- [ ] Deixar feedback construtivo

---
