# Glossário — Siglas e Acrônimos

> Referência rápida de siglas comuns em Engenharia de Software. Termos por extenso: [[Glossario - Termos de Engenharia de Software]].

## Arquitetura & Design
- **OOP** — Object-Oriented Programming ([[Orientacao a Objetos]])
- **DDD** — Domain-Driven Design ([[Domain-Driven Design (DDD)]])
- **SOLID** — SRP, OCP, LSP, ISP, DIP ([[SOLID Principles]])
- **SRP / OCP / LSP / ISP / DIP** — os 5 princípios SOLID
- **DRY / KISS / YAGNI** — princípios de simplicidade ([[DRY, KISS e YAGNI]])
- **CQRS** — Command Query Responsibility Segregation ([[Event-Driven, CQRS e Event Sourcing]])
- **EDA** — Event-Driven Architecture
- **MVC / MVVM / MVP** — padrões de UI/apresentação
- **SoC** — Separation of Concerns
- **POLA** — Principle of Least Astonishment

## APIs & Rede
- **REST** — Representational State Transfer ([[APIs REST - Fundamentos e Design]])
- **RPC / gRPC** — Remote Procedure Call ([[gRPC]])
- **HTTP / HTTPS** — HyperText Transfer Protocol (Secure) ([[Redes - TCP-IP, HTTP, DNS e TLS]])
- **TCP / UDP / IP** — protocolos de transporte/rede
- **DNS** — Domain Name System
- **TLS / SSL** — Transport Layer Security
- **CORS** — Cross-Origin Resource Sharing
- **gRPC** — gRPC Remote Procedure Calls
- **URI / URL** — identificador/localizador de recurso

## Dados & Banco
- **SQL / NoSQL** — linguagem de consulta relacional / não relacional ([[SQL vs NoSQL]])
- **ACID** — Atomicity, Consistency, Isolation, Durability ([[Transacoes e ACID]])
- **BASE** — Basically Available, Soft state, Eventually consistent
- **CAP** — Consistency, Availability, Partition tolerance ([[Teorema CAP e Sistemas Distribuidos]])
- **OLTP / OLAP** — processamento transacional / analítico ([[Engenharia de Dados]])
- **ETL / ELT** — Extract-Transform-Load / Extract-Load-Transform
- **DW** — Data Warehouse
- **CRUD** — Create, Read, Update, Delete
- **ORM** — Object-Relational Mapping
- **1NF/2NF/3NF/BCNF** — formas normais ([[Modelagem de Dados e Normalizacao]])

## Infra, DevOps & Cloud
- **CI / CD** — Continuous Integration / Delivery/Deployment ([[CI-CD - Integracao e Entrega Continua]])
- **IaC** — Infrastructure as Code
- **K8s** — Kubernetes ([[Kubernetes]])
- **VM** — Virtual Machine
- **IaaS / PaaS / SaaS / FaaS** — modelos de serviço cloud ([[Computacao em Nuvem - Fundamentos]])
- **SRE** — Site Reliability Engineering
- **SLI / SLO / SLA** — indicador / objetivo / acordo de nível de serviço ([[Observabilidade]])
- **DORA** — métricas de entrega (DevOps) ([[DevOps - Cultura e Praticas]])
- **OS** — Operating System ([[Sistemas Operacionais - Fundamentos]])

## Segurança
- **OWASP** — Open Worldwide Application Security Project ([[OWASP Top 10]])
- **AuthN / AuthZ** — Authentication / Authorization ([[Autenticacao vs Autorizacao]])
- **OAuth / OIDC** — delegação de acesso / OpenID Connect ([[OAuth 2.0 e OpenID Connect]])
- **JWT** — JSON Web Token ([[JWT (JSON Web Token)]])
- **MFA / 2FA** — autenticação multifator
- **RBAC / ABAC** — controle de acesso por papel / atributo
- **XSS / CSRF / SQLi** — ataques web comuns
- **PKI** — Public Key Infrastructure
- **AES / RSA / ECC** — algoritmos de criptografia ([[Criptografia - Hashing, Encryption e Senhas]])

## Testes & Qualidade
- **TDD / BDD / ATDD** — desenvolvimento guiado por testes / comportamento / aceitação ([[TDD - Test-Driven Development]])
- **E2E** — End-to-End (testes) ([[Testes - Fundamentos e Piramide]])
- **QA** — Quality Assurance
- **SAST / DAST / SCA** — análise estática / dinâmica / de composição (segurança)
- **DRY** — (ver princípios)

## IA
- **LLM** — Large Language Model ([[LLMs - Fundamentos]])
- **GPT** — Generative Pre-trained Transformer
- **RAG** — Retrieval-Augmented Generation ([[RAG - Retrieval-Augmented Generation]])
- **MCP** — Model Context Protocol ([[MCP - Model Context Protocol]])
- **RLHF** — Reinforcement Learning from Human Feedback
- **CoT** — Chain-of-Thought ([[Prompt Engineering]])
- **NLP** — Natural Language Processing

## Processo & Geral
- **SDLC** — Software Development Life Cycle ([[SDLC - Ciclo de Vida do Software]])
- **SWEBOK** — Software Engineering Body of Knowledge ([[SWEBOK - Corpo de Conhecimento]])
- **ADR** — Architecture Decision Record ([[45 - DECISOES ARQUITETURAIS/_INDEX]])
- **RFC** — Request for Comments
- **MVP** — Minimum Viable Product (ou Model-View-Presenter — depende do contexto)
- **KPI** — Key Performance Indicator
- **DLQ** — Dead Letter Queue ([[Padroes de Mensageria e Garantias de Entrega]])
- **Big-O** — notação de complexidade ([[Complexidade Algoritmica (Big-O)]])
