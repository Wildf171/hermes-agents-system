FLUXO DE DADOS: Candidato Envia CV → RH Acessa
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  1. CANDIDATO REGISTRA                                                  │
│     ╔════════════════════════════════════════════╗                     │
│     ║ App Flutter                                ║                     │
│     ║ POST /api/auth/registrar                   ║                     │
│     ║ { email, nome, senha }                     ║                     │
│     ╚════════════════════════════════════════════╝                     │
│               ▼                                                          │
│     ┌───────────────────────────────────────────┐                      │
│     │ db.usuarios (novo)                        │                      │
│     │ {                                         │                      │
│     │   tipo: "candidato"                       │                      │
│     │   eh_candidato: true                      │                      │
│     │   permissoes: ["enviar_cv", ...]          │                      │
│     │ }                                         │                      │
│     └───────────────────────────────────────────┘                      │
│               ▼                                                          │
│     ┌───────────────────────────────────────────┐                      │
│     │ JWT Token (24h)                           │                      │
│     │ {access_token, refresh_token}             │                      │
│     └───────────────────────────────────────────┘                      │
│                                                                          │
│  2. CANDIDATO ENVIA CV                                                  │
│     ╔════════════════════════════════════════════╗                     │
│     ║ App Flutter                                ║                     │
│     ║ POST /api/curriculos/upload                ║                     │
│     ║ Header: Authorization: Bearer JWT          ║                     │
│     ║ Body: multipart/form-data (PDF)            ║                     │
│     ╚════════════════════════════════════════════╝                     │
│               ▼                                                          │
│     ┌─────────────────────────────────────────────┐                    │
│     │ Validações                                  │                    │
│     │ ✓ JWT válido                                │                    │
│     │ ✓ Permissão "enviar_cv"                    │                    │
│     │ ✓ PDF válido (< 10MB)                      │                    │
│     │ ✓ Calcular SHA256                          │                    │
│     └─────────────────────────────────────────────┘                    │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ S3 Upload                                      │                 │
│     │ /curriculos/{usuario_id}/v1_hash.pdf           │                 │
│     └────────────────────────────────────────────────┘                 │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ db.curriculos (novo)                           │                 │
│     │ {                                              │                 │
│     │   usuario_id: "...",                           │                 │
│     │   versao: 1,                                   │                 │
│     │   arquivo_url: "s3://...",                     │                 │
│     │   arquivo_hash: "abc123...",                   │                 │
│     │   ativo: true                                  │                 │
│     │ }                                              │                 │
│     └────────────────────────────────────────────────┘                 │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ db.auditoria                                   │                 │
│     │ "usuario_123 fez upload_curriculo"             │                 │
│     └────────────────────────────────────────────────┘                 │
│                                                                          │
│  3. CANDIDATO ACEITA LGPD                                               │
│     ╔════════════════════════════════════════════╗                     │

│     ║ { consentimento: true }                    ║                     │

│     │ }                                         │                      │
│     └───────────────────────────────────────────┘                      │
│               ▼                                                          │
│     ┌───────────────────────────────────────────┐                      │
│     │ db.auditoria                              │                      │
│     │ "usuario_123 deu consentimento LGPD"      │                      │

│  4. RH ACESSA PERFIL DO CANDIDATO                                       │
│     ╔════════════════════════════════════════════╗                     │
│     ║ Web Neo RH System                          ║                     │
│     ║ GET /api/candidatos/:id                    ║                     │
│     ║ Header: Authorization: Bearer JWT_RH       ║                     │

│     └─────────────────────────────────────────────┘                    │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ db.candidatos.find()                           │                 │

│     │ Retorna: nome, email, telefone, cv_url, ...    │                 │
│     └────────────────────────────────────────────────┘                 │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ db.curriculos_acesso (novo)                    │                 │
│     │ Auditoria LGPD:                                │                 │
│     │ "rh_user_456 viu_cv candidato_123"             │                 │
│     │ {                                              │                 │

│     │   usuario_acesso_id: "456",                    │                 │
│     │   tipo_acesso: "visualizacao",                 │                 │
│     │   timestamp: now,                              │                 │
│     │   resultado_acesso: "sucesso"                  │                 │
│     │ }                                              │                 │
│     └────────────────────────────────────────────────┘                 │
│               ▼                                                          │
│     ┌────────────────────────────────────────────────┐                 │
│     │ Response JSON                                  │                 │
│     │ + S3 URL do CV (iframe/viewer)                 │                 │
│     └────────────────────────────────────────────────┘                 │
│                                                                          │
