## 🔐 Checklist — Antes de Publicar Documento

Antes de considerar um documento "ready":

- [ ] Tem frontmatter com tipo, status, tags
- [ ] Tem título claro
- [ ] Tem pelo menos 1 link [[interno]]
- [ ] Está ligado em uma MOC
- [ ] Não tem typos/erros óbvios
- [ ] Tem "Ver também" ou "Relacionados"

### Status
- 🟢 **Completo** — Pronto para usar
- 🟡 **Base** — Estrutura criada, pronto para conteúdo
- ⚪ **Vazio** — Pasta criada, não tem docs
- 🔴 **Bloqueado** — Esperando something

### Tipos
- `#conceito` — Explicações teóricas
- `#projeto` — Seus sistemas
- `#padrão` — Design patterns
- `#checklist` — Workflows
- `#adr` — Decisions
