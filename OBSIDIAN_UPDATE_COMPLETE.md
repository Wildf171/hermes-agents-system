## 🎯 Cada Specialization Contém

### Structure Padrão
- **Expertise**: O que o agent pode fazer
- **Knowledge Bases**: Referências (CODE_TRAINING + KNOWLEDGE_BASE)
- **Trigger Keywords**: Quando usar este agent
- **Key Patterns**: 3-5 exemplos práticos de código
- **Checklist**: Validação do que gerar
- **References**: Links para documentos

### Exemplo: @frontend
```markdown
# Frontend Specialization - Complete Stack

**Agent**: @frontend
**Status**: ✅ Production-ready

## 🎯 Expertise
Generate production-ready components with React, HTML5, CSS...

## 🔑 Key Patterns
- HTML Semântico + ARIA
- Bootstrap Navbar
- Tailwind Classes
- SCSS with Mixins

## ✅ Checklist
- [ ] Use semantic tags
- [ ] aria-required for fields
- [ ] Functional components
...
```
